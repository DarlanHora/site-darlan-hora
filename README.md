# Site Darlan Hora

Cópia de segurança do site da marca Darlan Hora (criação de sites), no estado de 12/11/2026.

## O que tem aqui

- `canvas/Main.dc.html`: a página do site (layout escuro), com textos, calculadora de orçamento e formulário de contato.
- `canvas/canvas.json`: a configuração do canvas de design onde a página foi montada.
- `assets/foto-darlan.png`: a foto usada na seção Sobre.

## Importante

Estes arquivos são o site no formato do canvas de design do Claude. Eles guardam o visual e os textos, mas não rodam sozinhos num navegador nem numa hospedagem. O projeto publicável (Next.js) ainda vai ser construído a partir deles e entra neste mesmo repositório.
